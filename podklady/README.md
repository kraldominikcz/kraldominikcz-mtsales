## Pravidla
- **Repozitář musí zůstat soukromý** – ceníky a provize jsou interní.
- **Žádné osobní údaje zákazníků** (jména, telefonní čísla, adresy osob). Používej anonymizované vzory.
- Žádná hesla, tokeny ani API klíče – ty se předávají zvlášť, zabezpečeně.
- Novou verzi souboru nahraj s datem v názvu, starou nemaž.
